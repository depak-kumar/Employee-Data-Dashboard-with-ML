# Employee-Data-Dashboard-with-ML
Employee Retention Analysis Dashboard
Project Overview:
The Employee Retention Analysis Dashboard is an interactive tool designed to analyze and visualize employee data with a focus on retention. This dashboard allows users to explore various aspects of employee performance and retention, perform machine learning tasks, and visualize results to gain insights into factors affecting employee turnover.
![Screenshot 2024-08-11 115316](https://github.com/user-attachments/assets/2641e2d4-93de-42fc-a061-10f78828538b)
Features and Functionalities:
Data Upload and Preprocessing:

File Upload: Users can upload an Excel or CSV file containing employee data.
Data Preprocessing: The uploaded data is processed to handle missing values, encode categorical variables, and prepare it for analysis.
Data Visualization:

Retention Count: Visualize the distribution of employees who left vs. stayed using bar charts.
Performance Metrics: Display performance metrics like satisfaction level, last evaluation score, and average monthly hours in various plots to identify trends and patterns.
Machine Learning Integration:

Model Training and Evaluation: Train a machine learning model (e.g., Logistic Regression) to predict employee retention based on various features.
Model Accuracy: Display the accuracy of the trained model.
Classification Report: Provide a detailed classification report showing precision, recall, and F1-score for the model.
Model Saving and Download: Save the trained model to a file and provide an option for users to download it for future use.
Interactive Filters and Options:

Data Filtering: Users can filter the dataset based on various criteria such as satisfaction level, average monthly hours, and more. This helps in focusing on specific subsets of the data.
View Original Data: Option to view the original, unfiltered data directly within the dashboard for comparison and analysis.
Data Summary: Provide summary statistics and insights based on the filtered dataset.

How It Helps:
Insightful Analysis: Helps HR and management teams to understand employee retention patterns and identify factors that contribute to employee turnover.
Predictive Capabilities: Provides predictive insights on employee retention, allowing organizations to take proactive measures to reduce turnover.

Data-Driven Decisions: Facilitates data-driven decision-making by visualizing key performance metrics and model results.
This project provides a comprehensive tool for analyzing employee retention, incorporating both visual and predictive analytics to support HR decisions and improve organizational outcomes.
